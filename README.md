# Linux Monitoring v1.0

Этот проект направлен на освоение написания bash-скриптов для исследования системы Linux.
Ниже представлено описание задач.

## Задачи
### Часть 1. Проба пера
Напишите простой bash-скрипт, который принимает текстовый параметр и выводит его.
Если параметр является числом, выведите сообщение об ошибке.
### Часть 2. Исследование системы
Напишите скрипт, который выводит информацию о системе:
Имя хоста, временная зона, текущий пользователь, тип и версия ОС.
Дата, время работы системы, IP-адрес, маска сети, шлюз по умолчанию.
Информация о RAM и дисковом пространстве.
После вывода предложите сохранить данные в файл с именем в формате DD_MM_YY_HH_MM_SS.status.
### Часть 3. Визуальное оформление вывода
Улучшите скрипт из Части 2, добавив цветовое оформление.
Скрипт принимает 4 параметра для настройки цветов фона и текста.
Цвета шрифта и фона одного столбца не должны совпадать.
### Часть 4. Конфигурирование визуального оформления
Создайте конфигурационный файл для задания цветов.
Если параметры не указаны, используйте цветовую схему по умолчанию.
После вывода информации о системе покажите текущую цветовую схему.
### Часть 5. Исследование файловой системы
Напишите скрипт, который анализирует указанную директорию:
Количество папок, топ-5 самых тяжелых папок.
Количество файлов различных типов (конфигурационные, текстовые, исполняемые и т.д.).
Топ-10 файлов по размеру и топ-10 исполняемых файлов с их MD5-хешами.
Выведите время выполнения скрипта.
